# 🎨 MoodNFT: Solidify Your Emotions on Nero Chain

MoodNFT is a next-generation decentralized application (dApp) that bridges the gap between human emotion and immutable blockchain technology. By leveraging state-of-the-art AI generation models via Stability AI, this platform transforms your daily thoughts, feelings, and moods into highly unique, 1-of-1 digital artworks. Instead of letting your emotions fade into the ether, MoodNFT crystallizes them forever as Non-Fungible Tokens on a blazing-fast, highly secure blockchain. Every single piece of art generated isn't just displayed on an interface—it is perpetually stored on the completely decentralized InterPlanetary File System (IPFS) via Pinata, meaning your digital footprint remains censor-resistant and permanent.

Going beyond standard NFT minting platforms, MoodNFT provides a completely seamless, zero-friction user experience wrapped in a highly responsive Material UI dashboard. Users connect their decentralized wallets, input their emotional state in plain English, and watch as the system orchestrates a complex backend symphony. Within seconds, a beautiful algorithmic masterpiece is created, hashed, pinned to IPFS, and executed onto the blockchain, before instantly reflecting in the user's personal On-Chain Mint Gallery. Here, artificial intelligence meets irrevocable ownership, giving pure emotions tangible on-chain value.

## 📌 Requirements

To successfully run and interact with the MoodNFT platform, users must fulfill a few essential prerequisites. First, a dedicated Web3 browser extension like MetaMask is required to inject the necessary `window.ethereum` provider smoothly into the application. Second, you must have an active network configuration for the Nero Chain, specifically the NERO Testnet, to handle transaction routing securely. Finally, users need a minimal amount of NERO test tokens in their wallet specifically to cover the computational gas logic for on-chain mints. For local development, standard Node.js environments coupled with active API credentials from both Pinata (JWT) and Stability AI are strictly necessary to fuel the backend endpoints.

- **Blockchain Network**: NERO Testnet

## 🏗️ How the Project is Built on the NERO Chain

The integration of blockchain technology is fundamentally powered by `ethers.js` interfacing gracefully with the underlying NERO node infrastructure. When a user finalizes their digital mood reflection, our custom Web3 bridge natively broadcasts a powerfully signed payload targeting the NERO network nodes. We specifically chose the **NERO Chain** due to its exceptionally low latency and high-throughput architectural design, meaning users don't have to wait agonizing minutes for block confirmations; their art is sealed in seconds. Once NERO confirms the state change, the cryptographic token URI perfectly bounds the IPFS hash with the user's wallet address inside the blockchain's eternal ledger. The decentralized gallery then recursively pings the NERO chain to map out the exact `totalSupply` and visually decodes back your entire transaction history flawlessly.
